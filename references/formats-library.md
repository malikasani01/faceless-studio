# Formats that repeat

A format is a beat structure you can run fifty times with different content. Pick three or four and get good at them. Novelty is expensive; repetition is what builds a recognisable channel.

Each format below is written as beats. Fill them with the niche.

## 1. The correction

Someone believes a thing. The thing is incomplete. Here is the better version.

1. Name the belief in the viewer's own words. (0 to 3 s)
2. Concede what is right about it. This buys permission.
3. The turn: what it misses.
4. The mechanism: *why* it misses it.
5. One concrete thing to do instead.
6. Silent end card.

Strongest for building authority. Works when you genuinely know something.

## 2. The hidden cost

A thing that looks free is not.

1. The ordinary moment, shown plainly.
2. "Technically you did X." Agree with the viewer.
3. What is actually still happening underneath.
4. The contrast: what the real version looks like.
5. The takeaway as a sentence they can repeat.

Strongest for retention. The gap between appearance and reality holds attention.

## 3. The breakdown

One thing, in its parts.

1. Most people think this is one step.
2. It is actually [n] parts.
3. Part one, named, with one image.
4. ... each part, same rhythm.
5. The parts as a single loop.

Strongest for saves and shares. Give the framework a name and people repeat it for you.

## 4. The guided thing

The viewer does something during the video rather than learning about it.

1. Starting state, named.
2. A prompt. Then a real pause — silence, no narration.
3. They act.
4. The next prompt. Pause again.
5. Ending state, named.

Strongest for trust. Rare, because most creators cannot bear the silence. Do not fill the pauses.

## 5. The ambient block

A long session with structure: an opening, work time, a break, more work time.

Almost no production cost once the format exists, and it earns the watch time that short videos cannot. One of these a week alongside the short content is a good trade.

---

## Choosing

Start with two: one that teaches (1, 2 or 3) and one that is cheap to produce in volume (5). Add a third once the first two have run ten times each.

Track which one holds attention longest and make more of that one. That is the only format research that matters.
